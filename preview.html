Maison

The Maison Record. A couture house's record book, not an analytics console. Ivory stock, noir ink, one thread of antique gold, and enough silence around a figure that the figure means something. Every ratio below is measured against the ground, not chosen by eye.

When a sample cannot support a rate, the counts take the value slot and no percentage is rendered at all — not greyed, not parenthesised, not behind a tooltip. The figure slot must always be able to hold "5 of 32".

Elevation, shape and motion

This system has no shadows. Not few — none. Depth is the ivory ground, a barely-raised surface for floating chrome, and 1px hairlines. A drop shadow anywhere is a regression to the dashboard this replaced.

Guardrails

Do

  • Group with a 1px hairline and space.
  • Use gold-text for anything read at text size.
  • Set every measured number in Bodoni, tabular.
  • Give one figure per screen the gold and the scale.
  • Carry counts alongside every rate.
  • Honour prefers-reduced-motion.
  • 44px targets and press feedback on coarse pointers.
  • Re-measure every data colour if the ground changes.

Don't

  • Put content in a card.
  • Add a drop shadow anywhere.
  • Put an icon beside a navigation label.
  • Set Bodoni below 1.25rem.
  • Use gold as a data series colour.
  • Write an eyebrow above a heading.
  • Rely on hover for anything a phone user needs.
  • Import glass, backdrop blur, or a system font stack.
